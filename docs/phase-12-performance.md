# Фаза 12 — Performance baseline

## Реалізовано

- Усі основні маршрути завантажуються окремими модулями.
- HLS-плеєр і зовнішній embed-плеєр відокремлені від маршруту перегляду та завантажуються лише після отримання playback-сесії.
- Модуль `/watch` зменшено приблизно з 537 KB до 12 KB до стиснення; HLS-код не потрапляє в початковий пакет.
- Постери використовують стабільне співвідношення 2:3, intrinsic width/height, `loading="lazy"` і `decoding="async"`.
- `npm run budget:check` перевіряє статичний граф початкових JavaScript-модулів за production manifest.

## Поточний бюджет

- Початковий JavaScript: 184.0 KB gzip.
- Ліміт: 200 KB gzip.
- Результат: проходить.

## Що потребує середовища preview або production

- Mobile Lighthouse для LCP, CLS та INP.
- Перевірка реальних TMDB-зображень через CDN і повільну мережу.
- Перевірка кешування статичних ресурсів та заголовків CDN.
